How articles are written

Everything is written in Markdown, so a post can mix prose, mathematics, tables and syntax-highlighted code without fighting a word processor: 

def binary_search(items, target):
    lo, hi = 0, len(items) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if items[mid] == target:
            return mid
        if items[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

Every code block gets a language label and a copy button, in light and dark themes alike.
